Ajustar stock físico

Registra el nuevo conteo físico tras una venta en el local, ingreso de mercadería o recuento. No modifica las unidades reservadas para clientes.

Editar producto

El ID interno UUID no se puede cambiar: mantiene las relaciones con reservas, imágenes y stock. El SKU sí es editable.

Para ventas presenciales o reposiciones utiliza «Ajustar stock», que registra el motivo y evita cambios accidentales.

El precio y estado actual se conservan en el historial de versiones. Las reservas anteriores mantienen su nombre, precio unitario y subtotal originales.

Imágenes del producto

Hasta 8 imágenes por producto. JPG, PNG o WEBP, máximo 3 MB cada una. La primera imagen subida será principal.
